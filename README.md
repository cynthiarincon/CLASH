## Overview

CLASH! is a fun web game where you compete against the computer in a rock-paper-scissors style game. Choose **Smash**, **Wrap**, or **Slice**, or randomize the choices for both players. The game tells you if you **win**, **lose**, or **tie**. Background music plays during the game.

## How to Play

1. Enter **Smash**, **Wrap**, or **Slice** in the input box.
2. Click **CLASH!** to play against the computer.
3. Or click **RANDOMIZE** for both random choices.
4. See the result and click **RESET** to play again.

## Features

- Player input validation
- Randomized computer moves
- Win, lose, or tie results
- Responsive design for mobile and desktop
- Fun comic-style font and visuals
- Background music
